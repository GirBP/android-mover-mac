# Android Mover


Простий macOS-додаток для перенесення файлів між Android-телефоном і Mac в обидва боки — як через Провідник на Windows: відкрив, вибрав теку на телефоні, вибрав теку на Mac, натиснув «Перемістити» (або навпаки — «На телефон…» чи перетягнув файли з Finder).

**Головне: дати файлів зберігаються.** Дата модифікації переноситься з телефона (`adb pull -a`), дата створення у Finder виставляється такою самою. EXIF та інші метадані всередині файлів не втрачаються (копіювання побайтове).

**Безпечне переміщення.** «Перемістити» видаляє файли з телефона **лише після** перевірки, що копія повна (збіг кількості та розмірів усіх файлів). Обірвався кабель — на телефоні все лишилось.

## Збирання

```bash
scripts/build_app.sh
```

Готовий додаток: `dist/Android Mover.app` — перетягніть у «Програми» й запускайте.

Тести: `swift test`.

## Перше налаштування телефона (один раз, ~2 хвилини)

macOS не вміє MTP як Windows, тому додаток працює через офіційний ADB від Google:

1. Підключіть телефон кабелем USB.
2. На телефоні: **Налаштування → Про телефон → 7 разів торкніться «Номер збірки»** (з'явиться режим розробника).
3. **Налаштування → Для розробників → увімкніть «Налагодження USB»**.
4. Запустіть Android Mover. Якщо ADB ще не встановлено — додаток сам запропонує завантажити його (~13 МБ з офіційного dl.google.com). Альтернатива: `brew install --cask android-platform-tools`.
5. На телефоні з'явиться запит «Дозволити налагодження USB?» — поставте галочку «Завжди дозволяти з цього комп'ютера» і підтвердьте.

Далі — просто підключаєте кабель і відкриваєте додаток.

## Використання

- **Бічна панель зліва** (згортається системною кнопкою в тулбарі) — три секції:
  - **«Пристрій»** — усі підключені телефони (клік перемикає активний), бейдж стану
    (підключено / не авторизовано / offline) і вільне місце активного пристрою.
  - **«Телефон»** — швидкі місця (Камера, Завантаження, Зображення, Корінь) і **«Обране на
    телефоні»**: кнопка «+» чи пункт контекстного меню «Додати в обране» на шляху зберігають
    поточну теку (окремо для кожного телефону), видалення — правим кліком по рядку обраного.
  - **«Mac»** — кілька збережених тек призначення: **«Обрати теку…»** або перетягніть теку з
    Finder прямо в цю секцію, щоб додати її й одразу зробити активною. Клік по рядку перемикає
    активну теку, правий клік — видаляє зі списку (файлів на диску не чіпає).
- **Шлях телефону — клікабельні «хлібні крихти»**: кожен компонент шляху окремою кнопкою,
  довгий шлях стискається з середини («…»-меню посередині). Клік по порожньому місцю рядка
  перемикає на текстове поле для ручного вводу шляху (Escape чи Enter повертає назад до крихт).
- **Подвійний клік по файлу — швидкий перегляд (Quick Look)** без перенесення: файл тихо стягується у тимчасовий кеш і відкривається як у Finder (фото, відео, PDF…). Повторний перегляд — миттєвий. Великий файл тягнеться довше — внизу видно спінер і кнопку скасування. Подвійний клік по теці — відкрити її. Після перегляду біля імені файлу з'являється **мініатюра** замість іконки — без жодного додаткового трафіку з телефона (генерується з уже стягнутої копії).
- **Мініатюри фото (JPEG/HEIC) показуються одразу**, без перегляду: для видимих рядків додаток читає лише перші 64 КБ файла — вбудовану EXIF-мініатюру, не ціле фото (~64 КБ замість 3–8 МБ на знімок). Результат кешується на Mac, наступного разу з телефона нічого не читається. Вимкнути можна в Settings (⌘,).
- **Перетягніть рядок у Finder** — файл чи тека стягуються з телефона рівно в момент, коли ви відпускаєте кнопку миші над вікном Finder (перетягування саме по собі нічого не тягне). Тягнуться всі виділені рядки разом; помилку під час перетягування показує сама macOS.
- Виберіть файли/теки (⌘-клік — кілька). Куди копіювати — меню **«Куди: …»** унизу (перемикає між збереженими теками, «Обрати іншу теку…», «Показати у Finder») або галочка в бічній панелі, секція **«Mac — куди копіювати»**. Якщо диск призначення від'єднано чи він лише читається — рядок теки і кнопка «Куди:» покажуть попередження, а чому «Копіювати/Перемістити» неактивні, пояснить підказка при наведенні.
- **Копіювати** — телефон не чіпаємо. **Перемістити** — після перевірки копії файли видаляються з телефона.
- Правий клік по файлу/теці: **Перейменувати…**, **Видалити з телефона…** (з підтвердженням, безповоротно). Кнопка з текою «+» у тулбарі — **нова тека** на телефоні.
- Поле з лупою поряд зі шляхом — **пошук по імені** у поточній теці (регістронезалежний, працює з кирилицею). Прихований фільтром вибір не скидається.
- **Приховані файли** («.»-імена) сховані за замовчуванням — кнопка ока в тулбарі показує/ховає їх. Службові тимчасові теки додатку (`.androidmover-tmp-*`) не показуються ніколи, незалежно від тумблера.
- Вільне місце на телефоні (бічна панель, секція «Пристрій») оновлюється при переході в теку і раз на ~30 с. Коли файли видалили чи перемістили, Галерея (MediaStore) фоново, best-effort, підхоплює зміни без ручного «Пересканувати».
- **«На телефон…»** (унизу) або **перетягніть файли/теки з Finder прямо в таблицю** — копіює їх у поточну відкриту теку телефона. Перед появою у видимому місці файл спершу лягає в тимчасову теку на телефоні й звіряється (кількість і розміри) — часткова копія після обриву чи зіпсованого передавання ніколи не потрапляє в призначення. Колізія імені на телефоні вирішується автоперейменуванням «(1)», як і при копіюванні з телефона.
- **Черга операцій** (як Downloads у Safari) — панель унизу вікна показує всі копіювання/переміщення/push: одна виконується, решта чекають «У черзі», браузинг телефона працює далі. Кожен рядок можна скасувати; для завершених — «Показати у Finder», «Деталі…» (повний список файлів) і «×», щоб прибрати з панелі. Скасування ніколи не видаляє нічого з телефона.
- Кнопка з годинником у тулбарі — **Історія операцій**: журнал копіювань, переміщень і видалень (з провалами й скасуваннями), розгортання запису показує елементи, «Показати у Finder» для тих, що досі на диску.
- Сортування таблиці й ширини колонок (перетягніть межу заголовка) запам'ятовуються між запусками.
- Телефон відключився посеред роботи? Замість миттєвого повернення на екран підключення додаток 15 секунд показує жовтий банер «Телефон відключено — очікую…» над таблицею (якщо телефон повернеться — перегляд продовжується без переривань).
- **Налаштування** (⌘,) — тумблер «Вести історію операцій» (можна вимкнути) і кнопка «Очистити історію…» (працює завжди, незалежно від тумблера).

## Wi-Fi без кабеля (Android 11 і новіші)

1. На телефоні: **Налаштування → Для розробників → «Бездротове налагодження»** (телефон і Mac — в одній мережі Wi-Fi).
2. У застосунку: бічна панель → **«Wi-Fi без кабеля…»** (або та сама кнопка на екрані «Підключіть Android-телефон»).
3. **Один раз спарити:** на телефоні натисніть «Спарювати пристрій за допомогою коду» — він покаже адресу з портом і шестизначний код; введіть їх у розділі «1. Спарити».
4. **Під'єднати:** адреса з портом угорі екрана «Бездротове налагодження». Порт тут інший, ніж у діалозі з кодом, і змінюється щоразу, як телефон перезавантажили. Введіть їх у розділі «2. Під'єднати». Якщо adb уміє автопошук (mDNS), знайдені телефони показуються зверху — досить натиснути «Під'єднати».

Далі все як по кабелю: той самий список пристроїв (значок Wi-Fi замість телефона), ті самі копіювання, переміщення й push. Обране на телефоні та журнал незавершених операцій прив'язані до самого телефона (`android_id`), а не до адреси — після перезавантаження чи переходу на кабель вони на місці. Wi-Fi помітно повільніший за USB: великі переноси краще кабелем. Від'єднати — правий клік по пристрою в бічній панелі.

## Клавіатура

| Клавіші | Дія |
|---|---|
| ⌘⇧C | Копіювати вибране на Mac |
| ⌘⇧M | Перемістити вибране на Mac (з підтвердженням) |
| ⌘⇧U | «На телефон…» — вибрати файли з Mac |
| ⌘⌫ | Видалити вибране з телефона (з підтвердженням) |
| ⌘↑ | Перейти в батьківську теку |
| ⌘R | Оновити список файлів |
| Space | Quick Look для одного вибраного файла |
| ⌘F | Фокус у поле пошуку |
| ⌘⇧. | Показати/сховати приховані файли |
| ⌘⇧G | Редагувати шлях (хлібні крихти → текстове поле) |
| ⌘⇧A | Додати поточну теку в обране |
| ⌘⌥S | Згорнути/розгорнути бічну панель |

Усі пункти дублюються в меню (File → після «Нове вікно», View) з тим самим `.disabled`, що й відповідні кнопки.

## Надійність

Обірвався кабель посеред копіювання чи переміщення (в обидва боки)? Додаток не здається одразу і не тягне все заново з нуля:

1. Якщо `pull` завершився з помилкою (не через скасування) або перевірка копії після нього не збіглася — додаток чекає, поки телефон з'явиться знову (`adb wait-for-device`, до 2 хвилин).
2. Після повернення телефона докачує **лише відсутні або биті файли** елемента — не пересилає те, що вже прийшло цілим.
3. Знову перевіряє копію. Якщо збіглося — перенесення завершується як зазвичай (для «Перемістити» — джерело на телефоні видаляється лише тепер, після успішної перевірки).
4. Так до 15 спроб для обривів зв'язку (кожна чекає телефон до 2 хвилин, пауза між спробами зростає до 8 с) і до 3 спроб, якщо перевірка копії не збігається. Якщо не вдалося жодного разу — чесний провал: джерело на телефоні лишається недоторканим, у Mac нічого часткового не з'являється.

Скасування працює на будь-якому кроці цього циклу — і під час очікування телефона, і під час докачки.


Таймаут будь-якої adb-команди — це пауза БЕЗ виводу, а не загальна тривалість команди (перелік теки на 50к файлів триває, скільки треба, обривається лише те, що замовкло).
Якщо частину дат створення виставити не вдалось — файли всі на місці, а підсумок покаже, скільки їх, у попередженні.
Тимчасові теки `.androidmover-tmp-*`, що лишились від аварійно перерваного запуску, прибираються самі при наступному підключенні.

## Надійність — що гарантовано при обриві, краху й збоях

- **Телефон лише читається**, доки копія на Mac не перевірена. Копія пишеться у приховану тимчасову теку на тому ж диску і **атомарно** перейменовується в призначення — півфайла у твоїй теці не буває.
- **Перевірка копії:** кількість і розміри — завжди; **md5** (телефон рахує свій, Mac — свій) — перед будь-яким видаленням з телефона (Settings ⌘, → можна «завжди» або «ніколи»). Розбіжність → файл перекопіюється, з телефона нічого не видаляється.
- **Обрив кабеля / Wi-Fi / перезавантаження телефона** посеред копіювання (в обидва боки): додаток чекає на пристрій (до ~30 хв, видно «спроба N») і **докачує лише відсутні або биті файли**, а не все спочатку. Якщо файл на телефоні дописався після лістингу — розміри перечитуються і копія оновлюється.
- **«Перемістити» видаляє лише після перевірки саме цього файла.** Теки видаляються **пофайлово** (лише перевірені файли), потім прибираються лише порожні теки — файл, що з'явився на телефоні під час переносу, і його тека лишаються (з попередженням).
- **Крах, kill, вимкнення живлення:** журнал незавершених операцій; при наступному запуску — банер «Незавершена операція: Продовжити / Відхилити». «Скопійовано, але не видалено» довидаляється лише після повторної перевірки (копія на Mac існує, розмір збігається з телефоном зараз).
- **Диск призначення заповнився чи від'єднаний:** елемент чесно провалюється до старту (без марних спроб), решта черги — теж, з поясненням у рядку операції.
- **Mac не засинає** сам, доки йде операція (сон розриває USB-сесію).
- **Скасування** ніколи нічого не видаляє і не лишає півфайлів у призначенні.
- Чого **не** гарантовано: `rm` кількох файлів у батчі — окремі файли атомарні, але обрив посеред батчу може лишити частину вже видаленою (їхні копії на Mac при цьому повні і перевірені); md5 не захищає від збою самого диска Mac після копіювання — тримай резервні копії важливого.

## Обмеження (поки що)

- Символічні посилання не переносяться (в обидва боки).
- Імена файлів з символом нового рядка не підтримуються.
- Push (Mac → Android) звіряє дати найкраще можливе (best-effort): якщо дата модифікації на телефоні відрізняється від Mac більш ніж на 2 с (FUSE-поведінка неоднорідна по виробниках), файл усе одно на місці — просто попередження в підсумку, не провал.
