# docs — карта документів

- `SPEC.md` — визначення «готово» (акцептанс-критерії).
- `architecture/ARCHITECTURE.md` — архітектура та інваріанти.
- `qa/QA-DEVICE.md`, `qa/A11Y-CHECKLIST.md` — ручні чеклісти на реальному телефоні та VoiceOver.

У корені лишаються `README.md` (для користувача) і `CHANGELOG.md` (історія версій).
